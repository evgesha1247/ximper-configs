## Памятка ассистенту (читать первым делом)

- Дистрибутив: **ALT Linux**, пакеты ставятся **только через epm**
  (`epm install имя`, для стороннего софта — `epm play имя`).
  НИКОГДА не предлагать pacman/apt — пользователь уже многократно поправлял.
- Обращение на «ты», живой тон. Пользователь учится — объяснять просто,
  с расшифровкой неочевидных мест, но без воды.
- Терминал: **kitty**, шелл: **zsh + starship**, окружение: **Hyprland (Wayland)**.
- Тема оформления: **Tokyo Night** (везде: терминал, GTK, промпт, будущий лаунчер).
- Ключевые цвета палитры, используемые в конфигах:
  `#7aa2f7` (синий, RGB 122;162;247), `#f7768e` (красный, 247;118;142),
  `#29394f` (сине-серая плашка, 41;57;79), `#a9b1d6` (основной текст, 169;177;214).
- Конфиги живут в репо `~/.config` (dotfiles), цель — будущий **установщик
  из git**: клонировать и накатить систему одной схемой (файл + симлинк).
- Пользователь знаком с симлинками и механикой git на базовом уровне,
  но терминальные мелочи лучше проговаривать каждый раз.
- Стиль команд: если пример содержит `ls` — помнить, что это алиас на **eza**
  (свой синтаксис флагов!), для «настоящего» ls — `command ls`.

## Этап 5 — что сделано

### Starship (промпт)
- Плитки/сегменты в стиле темы, переносы строк настроены (`add_newline`).
- Стрелка-успех: выбрана подходящая «низкая, узкая, скруглённая» из Nerd Font
  (вместо временной заглушки `ㅊ`).
- Символ ошибки: **☭ в ярко-красном** (`#f7768e`) — решение пользователя,
  оставить навсегда 🙂 (коммунизм горит красным — так и задумано).
- Синтаксис: цвет в starship пишется `fg:#7aa2f7 bold` (человекочитаемо).

### Eza (замена ls)
- Установлен, алиасы в zshrc:
  - `ls` → `eza --icons=auto --group-directories-first`
  - `ll` → `eza -la --icons=auto --group-directories-first --git`
  - `lt` → `eza -T --icons=auto --level=2` (дерево)
  - `la` → `eza -la --sort=modified --reverse` (свежее сверху)
  - `lnew` → 10 самых свежих объектов
- Грабль, который стоит помнить: **у eza флаги не как у ls**. `-lt` у eza — это
  `--time <FIELD>`, а не сортировка. Сортировка: `--sort=modified --reverse`.
  Если нужен настоящий ls — `command ls`.

### Zoxide (умный cd)
- Запоминает пути, прыжки по обрывкам: `z конф`, `zi` для интерактивного выбора.
- Подключение: `eval "$(zoxide init zsh)"`, алиасы `cd='z'`, `cdi='zi'`.
- База данных: `~/.local/share/zoxide` — в репо не носится.
- «Накормить» вручную: `zoxide add ~/.config`.

### Цветное меню автодополнения zsh
- Иконки в таб-меню zsh **невозможны** в принципе (ограничение zsh) —
  принято решение: цвета сейчас, иконки — позже через fzf (оверлей умеет всё).
- Блок в zshrc (до `eval "$(starship init zsh)"`):
  ```zsh
  autoload -Uz compinit && compinit
  zstyle ':completion:*:default' list-colors "${(s.:.)LS_COLORS}" \
    "di=38;2;122;162;247" \
    "ma=48;2;41;57;79;38;2;169;177;214"
  zstyle ':completion:*' menu select
  # заголовки групп убрали: строку format '[%d]' удалить/не добавлять
  ```
- Расшифровка ANSI (для памяти): `38;2;R;G;B` = цвет текста, `48;2;R;G;B` = фон,
  `2` = truecolor (24-бит). Hex→RGB: `#7aa2f7` = 122;162;247.
- Подстройка выделения (курсор меню): правится только `ma=...`.
- Заголовки вида `[local directory]` убраны — удалена строка
  `zstyle ':completion:*:descriptions' format '[%d]'`.

### Git-хозяйство
- `~/.zshrc` перенесён в репо: настоящий файл `~/.config/zsh/.zshrc`,
  на старом месте симлинк `~/.zshrc -> ~/.config/zsh/.zshrc`.
  Правило: **в репо — настоящий файл, снаружи — ссылка**. Править можно
  по любому пути, это один файл («дверь в ту же комнату»).
- `.gitignore` переключён с белого списка (`*` + `!`) на **чёрный список**:
  по умолчанию всё в репо, игнорим мусор/секреты (*.swp, *.key, .env и т.д.).
- Перед пушем обязательно: `git ls-files | grep -iE 'pass|token|secret|key|cred'`
  — аудит на случай случайно попавшего секрета.
- Будущий план: приватный репо на GitHub + удалённая копия для установщика.
