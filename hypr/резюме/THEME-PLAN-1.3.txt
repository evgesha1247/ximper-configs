## Памятка ассистенту (читать первым делом)

- Дистрибутив: **ALT Linux**, пакеты ставятся **только через epm**
  (`epm install имя`, для стороннего софта — `epm play имя`).
  НИКОГДА не предлагать pacman/apt — пользователь уже многократно поправлял.
- Обращение на «ты», живой тон. Пользователь учится — объяснять просто,
  с расшифровкой неочевидных мест, но без воды.
- Терминал: **kitty**, шелл: **zsh + starship**, окружение: **Hyprland (Wayland)**.
- Тема оформления: **Tokyo Night** (везде: терминал, GTK, промпт, wofi, swaync).
- Ключевые цвета палитры, используемые в конфигах:
  `#7aa2f7` (синий, RGB 122;162;247), `#f7768e` (красный, 247;118;142),
  `#29394f` (сине-серая плашка, 41;57;79), `#a9b1d6` (основной текст, 169;177;214),
  `#565f89` (приглушённый текст), `#bb9af7` (фиолетовый, рамки выделения),
  `#1a1b26` (фон), `#24283b` (карточки/панели).
- Конфиги живут в репо `~/.config` (dotfiles), цель — будущий **установщик
  из git**: клонировать и накатить систему одной схемой (файл + симлинк).
- Пользователь знаком с симлинками и механикой git на базовом уровне,
  но терминальные мелочи лучше проговаривать каждый раз.
- Стиль команд: если пример содержит `ls` — помнить, что это алиас на **eza**
  (свой синтаксис флагов!), для «настоящего» ls — `command ls`.
- Wofi: конфиг `~/.config/wofi/config`, стиль `~/.config/wofi/style.css`.
  Фон инпута `#1a1b26`, выделение `#29394f`, акцент `#7aa2f7`, рамка `#bb9af7`.
- Swaync: конфиг `~/.config/swaync/config.json`, стиль `~/.config/swaync/style.css`.
- **Hyprland 0.53 — НОВЫЙ синтаксис layerrule.** Старый формат
  `layerrule = blur, имя` НЕ работает («invalid field blur: missing a value»).
  Правильно: `layerrule = blur on, match:namespace имя_слоя`.
- **Грабли layerrule (проверено на живой системе):**
  - `ignorezero` — такого правила больше НЕТ, парсер ругается;
  - `ignorealpha` слитно — НЕ существует («invalid field type ignorealpha»);
  - правильное имя: **`ignore_alpha`** (через подчёркивание), пример:
    `layerrule = ignore_alpha 0, match:namespace swaync-control-center`;
  - `blur on, match:namespace ...` — проверено, работает.
- Слои swaync (подтверждено `hyprctl layers`): `swaync-control-center` (панель),
  `swaync-notification-window` (всплывашки; слой существует только пока
  уведомление на экране). Прозрачный слой растянут на весь монитор — без
  `ignore_alpha` даёт затемнение половины экрана вокруг карточки.
- **Как применять изменения (шпаргалка):**
  - swaync CSS: `swaync-client --reload-css` (на лету, без рестарта);
  - swaync конфиг: `swaync-client --reload-config`;
  - Hyprland (бинды, layerrule): `hyprctl reload`;
  - waybar: сигналов нет — `pkill waybar` и запустить заново;
  - systemd-сервисы: `systemctl --user restart имя.service`.
- **КРИТИЧЕСКОЕ ПРАВИЛО РАБОТЫ С ИЗОБРАЖЕНИЯМИ:** сначала смотреть на фото
  и обрабатывать контекст, ПОТОМ делать выводы. НИКОГДА не ставить галочку
  «фото есть — значит всё ок». Если на скриншоте ошибки — говорить об ошибках,
  а не об успехе. Пользователь дважды ловил ассистента на этом
  (два раза «стилизация прошла успешно» при красных попапах ошибок).
  Формулировка пользователя: «смотри на фотки, обрабатывай их контекст».
- При ошибке ассистента: признать сразу, исправить, без оправданий и
  длинных извинений. Пользователь ругается прямо — это нормально, не дуться.

## Этап 5 — что сделано

### Starship (промпт)
- Плитки/сегменты в стиле темы, переносы строк настроены (`add_newline`).
- Стрелка-успех: выбрана подходящая «низкая, узкая, скруглённая» из Nerd Font
  (вместо временной заглушки `ㅊ`).
- Символ ошибки: **☭ в ярко-красном** (`#f7768e`) — решение пользователя,
  оставить навсегда 🙂 (коммунизм горит красным — так и задумано).
- Синтаксис: цвет в starship пишется `fg:#7aa2f7 bold` (человекочитаемо).

### Eza (замена ls)
- Установлен, алиасы в zshrc:
  - `ls` → `eza --icons=auto --group-directories-first`
  - `ll` → `eza -la --icons=auto --group-directories-first --git`
  - `lt` → `eza -T --icons=auto --level=2` (дерево)
  - `la` → `eza -la --sort=modified --reverse` (свежее сверху)
  - `lnew` → 10 самых свежих объектов
- Грабль, который стоит помнить: **у eza флаги не как у ls**. `-lt` у eza — это
  `--time <FIELD>`, а не сортировка. Сортировка: `--sort=modified --reverse`.
  Если нужен настоящий ls — `command ls`.

### Zoxide (умный cd)
- Запоминает пути, прыжки по обрывкам: `z конф`, `zi` для интерактивного выбора.
- Подключение: `eval "$(zoxide init zsh)"`, алиасы `cd='z'`, `cdi='zi'`.
- База данных: `~/.local/share/zoxide` — в репо не носится.
- «Накормить» вручную: `zoxide add ~/.config`.

### Цветное меню автодополнения zsh
- Иконки в таб-меню zsh **невозможны** в принципе (ограничение zsh) —
  принято решение: цвета сейчас, иконки — позже через fzf (оверлей умеет всё).
- Блок в zshrc (до `eval "$(starship init zsh)"`):
  ```zsh
  autoload -Uz compinit && compinit
  zstyle ':completion:*:default' list-colors "${(s.:.)LS_COLORS}" \
    "di=38;2;122;162;247" \
    "ma=48;2;41;57;79;38;2;169;177;214"
  zstyle ':completion:*' menu select
  # заголовки групп убрали: строку format '[%d]' удалить/не добавлять
  ```
- Расшифровка ANSI (для памяти): `38;2;R;G;B` = цвет текста, `48;2;R;G;B` = фон,
  `2` = truecolor (24-бит). Hex→RGB: `#7aa2f7` = 122;162;247.
- Заголовки вида `[local directory]` убраны — удалена строка
  `zstyle ':completion:*:descriptions' format '[%d]'`.

### Git-хозяйство
- `~/.zshrc` перенесён в репо: настоящий файл `~/.config/zsh/.zshrc`,
  на старом месте симлинк. Правило: **в репо — настоящий файл, снаружи — ссылка**.
- `.gitignore` — чёрный список (по умолчанию всё в репо, игнорим мусор/секреты).
- Перед пушем: `git ls-files | grep -iE 'pass|token|secret|key|cred'`.
- Будущий план: приватный репо на GitHub + удалённая копия для установщика.
- **Симлинки и git:** коммитятся как пути; на другой машине могут превратиться
  в «тыкву» (битые), если цель не существует. Помнить при сборке установщика.

## Этап 6 — лаунчер wofi (сделано)

### Выбор лаунчера — аргументация (чтобы не переобсуждать)
- wofi не активно поддерживается, болячки не чинятся; у rofi с авг 2025 есть
  нативная Wayland-ветка 2.0. Решение пользователя: функциональность rofi
  избыточна → **wofi**, миграция на rofi несложна при необходимости.
- Меню питания правильнее делать не через лаунчер, а через **wlogout**.

### Конфиг (~/.config/wofi/config)
- За основу дефолт Ximper (адекватный) + наши правки: `prompt=Поиск…`,
  `width=600`/`height=400`, `no_actions=true`, `hide_scroll=true`,
  `term=kitty`, `image_size=28`.

### Стиль (~/.config/wofi/style.css)
- Шрифт JetBrainsMono Nerd Font 13px; фон инпута `#1a1b26`; выделение
  `#29394f` (единый язык с таб-меню zsh), текст выделенного `#7aa2f7`,
  рамка `#bb9af7` вместо кислотного `#7E01FF`; приглушение неподошедших
  пунктов `#565f89`. Пользователь проверил: «все норм».
- Хоткей: `bind = $mainMod, D, exec, wofi --show drun`.

## Этап 6 — центр уведомлений swaync (почти готов, см. «Открытые вопросы»)

### Диагностика: битый симлинк (грабль на будущее)
- `~/.config/swaync` был **симлинком на Ximper**:
  `swaync -> /etc/ximperdistro/hyprland/swaync` — битым (каталога-цели нет,
  пакет вычищен из системы, ссылка осталась). Симптом: пустые конфиги,
  swaync брал дефолты из `/etc/xdg/swaync/`.
- Лечение (сделано): `rm ~/.config/swaync`, `mkdir -p ~/.config/swaync`,
  `cp /etc/xdg/swaync/config.json /etc/xdg/swaync/style.css ~/.config/swaync/`.
- Проверка на других зомби: `find ~/.config -maxdepth 1 -type l ! -exec test -e {} \; -print`
  — выполнено, чисто (swaync был последним).

### config.json (~/.config/swaync/config.json)
- База — дефолт Ximper, анализирован построчно. Оставлено: позиция
  `positionX: right / positionY: top` (всплывашки справа сверху),
  `cssPriority: user`, `layer-shell: true` (для блюра),
  `timeout: 10 / timeout-low: 5 / timeout-critical: 0` (критические не исчезают).
- Изменения:
  - `notification-window-width: 500 → 400` (всплывашки компактнее);
  - в `widgets` добавлен `mpris` (виджет плеера; в widget-config уже был
    настроен, но не был включён в список — «мёртвый груз»).
- Отложено: `buttons-grid` (кнопка Wi-Fi на nmcli) — не включён, т.к.
  неизвестно, каким сетевым менеджером пользуется пользователь. Вернуться
  при разговоре о сети. Секции `scripts`/`notification-visibility` с
  `example.app.id` оставлены как образцы — никогда не срабатывают.
- Важно: JSON не поддерживает комментарии — пояснения давать рядом с кодом.
- Параметр `fit-to-screen: true` держит панель во всю высоту экрана;
  `control-center-height: 600` работает только при `false`. Решение
  за пользователем (компактная панель или во всю высоту) — НЕ ЗАКРЫТО.

### style.css (~/.config/swaync/style.css) — токйонайт-версия
- За основу взят Ximper-стиль (15k, богатая стилизация — не ванильный GTK).
- Все селекторы сохранены один в один (swaync привязан к именам классов),
  заменена только палитра:
  - панель `--cc-bg: rgba(26, 27, 38, 0.85)` (под блюр),
  - карточки `--noti-bg: 36, 40, 59` (#24283b), hover `#292e42`,
  - текст `#c0caf5`, приглушённое (время, подписи плеера) `#565f89`,
  - акцент `#7aa2f7`, рамки карточек `rgba(122, 162, 247, 0.25)`,
  - критические `#f7768e` (заготовка), свитч DND в ON — заливается акцентом.
- Время уведомлений приглушено (раньше спорило с заголовком по яркости).
- Закомментированные заготовки в файле: критические уведомления,
  приглушённые low-уведомления, кнопки buttons-grid.
- Стиль передан пользователю файлом в чате и установлен в
  `~/.config/swaync/style.css`.

### Blur слоёв (user-theme.conf)
- Добавлено (новый синтаксис):
  ```hyprlang
  layerrule = blur on, match:namespace swaync-notification-window
  layerrule = blur on, match:namespace swaync-control-center
  layerrule = ignore_alpha 0, match:namespace swaync-control-center
  layerrule = ignore_alpha 0, match:namespace swaync-notification-window
  ```
- Грабли по пути (все встречены реально, см. Памятку):
  1. первая попытка — старый синтаксис + опечатка `swaynccontrol-center`;
  2. `echo >>` запущен дважды → дублированные битые строки (чистились
     `sed -i '/layerrule.*swaync/d' ~/.config/hypr/user-theme.conf`);
  3. `ignorezero` — невалидно в 0.53;
  4. `ignorealpha` — невалидно, правильно `ignore_alpha`.
- Результат по скриншотам: панель и всплывашки с блюром в токйонайте,
  mpris работает (YouTube в Firefox: обложка, play), DND на месте.
  Затемнение пол-экрана вокруг всплывашки было ДО ignore_alpha — исчезло
  ПОСЛЕ него (но проверка прервана ошибкой ignorealpha, финальный скрин
  с ignore_alpha ещё не сделан — см. Открытые вопросы).
